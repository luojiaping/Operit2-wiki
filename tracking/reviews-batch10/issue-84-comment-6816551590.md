发现一处范围表述需要收窄。正文把 `npm run test:device-budget`称为 Edge 的“统一验收入口”（约第 32 行），但 `edge/README.md:37,50-53` 将其限定为 ESP32 完整模拟器验收；固件验收要加 `--firmware` 并检查额外产物，真机音频、网络和持续运行另行验收。建议明确写成“ESP32 完整模拟器验收入口”，避免读者把它理解成 Edge 全产品的统一验收。
